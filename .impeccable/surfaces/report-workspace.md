# Report workspace

Mode: Operate for intake/navigation; Read for explanations and source values.

Success: the user chooses a language, uploads a clear printed-English report as PDF or one photo, understands processing status, and can inspect, listen to or download the result.

Preserve Medivaanii and its original logo. Use the tokens and layout in DESIGN.md. Prioritize readable content, labelled actions and explicit errors. The implemented input choices are PDF, saved photo and native camera capture on supported phones. Desktop capture falls back to choosing a file.

States: empty, processing with filename, upload failed, report ready, translation pending/failed, empty labs, narration preparing/playing/paused/stopped/failed, PDF preparing. Retain source values, units, ranges and flag provenance. No silent paragraph truncation or narration autoplay.

Concept-only: pasted text, report Q&A, selectable medical terms and multiple-photo intake. Do not expose these as working controls until their contracts exist.
